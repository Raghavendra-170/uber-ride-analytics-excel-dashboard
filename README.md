# Uber Ride Analytics Dashboard 2024

An interactive Excel dashboard developed to analyze Uber ride booking data for 2024.

## Dashboard Overview

The dashboard provides insights into:

- Total bookings
- Total revenue
- Average booking value
- Customer ratings
- Driver ratings
- Monthly booking and revenue trends
- Vehicle type performance
- Booking status distribution
- Payment method usage
- Customer cancellation reasons
- Driver cancellation reasons
- Trip performance
- VTAT and CTAT metrics

## Data Preparation

Power Query was used to clean and transform the dataset, including handling missing values, standardizing fields, creating revenue logic, and preparing the data for PivotTable analysis.

## Dashboard Features

The dashboard includes interactive slicers for:

- Vehicle Type
- Booking Status
- Payment Method

These slicers allow users to interactively explore the dashboard.

## Project Structure

- `Dashboard` – Interactive dashboard
- `PVT_*` – Supporting PivotTables
- `Cleaned Data` – Cleaned dataset used for analysis
